# Passione Caccia – Redirect

Pagina di reindirizzamento usata per il QR code stampato sul merchandising.

Il QR code punta sempre a questo URL fisso:
`https://passione-caccia.github.io/`

Per cambiare la destinazione (es. se il gruppo Facebook viene bloccato di nuovo):

1. Apri il file `index.html` in questo repository
2. Clicca sulla matita (Edit) in alto a destra
3. Sostituisci il link nelle due righe che contengono l'URL attuale
4. Salva le modifiche (Commit changes)
5. Attendi 1-2 minuti che GitHub Pages si aggiorni
6. Verifica visitando `https://passione-caccia.github.io/`

Il QR code stampato non deve mai essere rifatto: basta aggiornare questo file.
